# 🛡️ REDTEAM-PAY — Frontend Web Console

> **Mastercard Account Takeover (ATO) Detection & Red-Team Attack Intelligence**  
> An exact, high-fidelity reproduction of the Emergent AI cyber red-team console built with **React**, **Vite**, **Tailwind CSS**, **Recharts**, and **Lucide Icons**.

---

## 🌟 Key Pages & Views

1. **`OVERVIEW`** — Stress-test Payment Defenses against GenAI-native fraud hero, quick stat counters, 3 Pillars (`IDENTIFY`, `GENERATE`, `DEFEND`), and core value propositions (`DIVERSITY`, `FIDELITY`, `EFFICACY`).
2. **`01 IDENTIFY` (Attack Taxonomy)** — Interactive 8-attack vector catalog with category filtering (`IMPERSONATION`, `IDENTITY`, `LLM ABUSE`, `SOCIAL ENGINEERING`, `MODEL EVASION`, `MONEY LAUNDERING`, `AUTOMATION`), channels, rails, novelty, and defensive signatures.
3. **`02 GENERATE` (Attack Campaign Generator)** — Sliders for Scale (1k-50k), Fraud ratio (1%-30%), and Evasion level (0%-100%), attack mix checkboxes, fraud vector distribution bar charts, and amount histogram buckets.
4. **`03 DEFEND` (Detection Dashboard)** — 4 KPI metrics with gradient underlines (Precision, Recall, F1, ROC AUC), interactive ROC Curve (AUC 1.000), Precision-Recall Curve, Confusion Matrix grid (TN, FP, FN, TP), per-vector recall bars, and top feature importance chart.
5. **`LIVE STREAM`** — Closed-loop live transaction stream simulator with realtime animated feed, risk bars, decision badges (`PASS` vs `BLOCK`), matrix tags (`TN`, `TP`, `FP`, `FN`), live counters, and controllable speed.
6. **`INVESTIGATE` (Fraud Investigation Console)** — Deep inspection view with transaction selector, big dollar amount displays, 4 status cards, top feature contribution bars with relative weights, and Claude Sonnet 5 narrative reasoning explanations.

## 🚀 Quick Start (Running Locally)

```bash
cd Frontend
npm run dev
```

The application will be running at: **`http://localhost:3000`**

To build for production:
```bash
npm run build
```
